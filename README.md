# AIと健康のセミナー

2026年10月27日、十条で開催する健康セミナーのWebスライドです。

公開ページ: https://peishangfeng.github.io/oji-ai-seminar-20261027/

## 閲覧方法

PCでは「前へ」「次へ」または左右の矢印キーで移動します。スマートフォンでは縦にスクロールします。全8枚で、実際のアプリ操作は講師が実演します。

## ファイル

- `index.html`: スライド本体（HTML/CSS/JavaScript）
- `assets/`: AIで作成したイメージ写真

ビルドは不要です。`index.html` と写真をそのまま静的配信します。出典はスライド下部の「出典・使い方」に記載しています。
